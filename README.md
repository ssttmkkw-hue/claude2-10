# 皇家竞技场 · Royal Arena

一个类似《皇室战争》玩法的召唤对战小游戏，用纯 Canvas 绘制，支持人机对战和**在线自动匹配的双人对战**。

## 部署到 Render（在线对战）

1. 在 Render 控制台点 **New → Blueprint**，选这个仓库，它会读取 `render.yaml` 自动创建服务；
   也可以手动建 **Web Service**：Runtime 选 Node，Build Command 填 `npm install`，Start Command 填 `npm start`。
2. 部署完成后，打开 Render 给的网址（形如 `https://royal-arena.onrender.com`）就能玩。
3. 两个人都打开这个网址并点「在线匹配」，服务器会自动把排队的玩家两两配对。

### 好友房间

- 点「好友房间 → 创建房间」，会得到一个 4 位房间号。
- 把房间号告诉好友，或者点「复制邀请链接」发给他（链接形如 `https://你的网址/?room=1234`，打开后会自动加入）。
- 好友点「好友房间 → 输入房间号加入」，用屏幕上的数字键输入房间号。
- 双方都进入房间后，**任意一方**点「开始游戏」即可开战。
- 一局结束后点「返回房间」，两人回到同一个房间，可以继续再开一局。

说明：
- 免费版服务 15 分钟没人访问会休眠，下次打开要等大约 30 秒唤醒。
- 对战在服务器上运行（20 帧/秒），客户端只负责显示和发送出牌指令，双方延迟相同，也无法作弊。
- 对局中有一方断线或退出，另一方直接获胜。
- `/healthz` 是健康检查接口，`/stats` 可以查看在线人数、排队人数、对局数和好友房间数。

本地运行：`npm install && npm start`，然后打开 http://localhost:3000 。在两个浏览器窗口里分别点「在线匹配」，就能自己和自己对战测试。

## 项目结构

```
server.js          Node 服务器：静态文件 + WebSocket 匹配 + 对战模拟
public/core.js     游戏核心逻辑（浏览器和服务器共用）：单位、卡牌、战斗、AI
public/index.html  画面、音效、操作、菜单、卡组构筑、联机客户端
render.yaml        Render 部署配置
```

## 怎么玩

- 人机对战不需要服务器，直接用浏览器打开 `public/index.html` 也能玩。手机竖屏体验最好，电脑上用鼠标也能玩。
- 把下方卡牌**拖到己方半场**放置部队，或者先点卡牌再点场地。
- 圣水会自动回复，上限 10；最后 60 秒变成 **双倍圣水**。
- 摧毁一座公主塔得 1 顶皇冠；摧毁国王塔直接 3 冠获胜。
- 3 分钟结束时皇冠数相同，进入 1 分钟 **加时赛**（先拿到皇冠者胜）。
- 摧毁对方的公主塔之后，可以在那一路的敌方半场放置部队。
- 电脑键盘：数字键 1–4 选卡。

## 其他功能

- **表情**：对战中点左下角的对话气泡，可以发 6 种表情，联机时对手能看到（电脑也会回应）。表情面板里可以屏蔽对方的表情。
- **奖杯和战绩**：赢了加奖杯、输了扣奖杯（在线对战 +30 / -20，三冠胜利额外 +5）。奖杯够了会晋升竞技场：新手草地 → 林间营地 → 石桥要塞 → 熔岩峡谷 → 冰霜王庭 → 皇家殿堂。战绩只保存在本机浏览器里。
- **昵称**：点主菜单右上角的昵称就能修改，联机时对手会看到。
- **断线重连**：在线对战中网络断开、切到别的应用或者刷新页面，30 秒内会自动连回原来的对局；超过 30 秒没回来算认输。对手掉线时，你会看到倒计时。

## 卡组构筑

- 主菜单点「卡组构筑」或点当前卡组预览进入。
- 共 3 套卡组可以切换；每套需要正好 8 张卡，选好后自动保存在浏览器里。
- 点下方卡牌：卡组有空位就直接加入；卡组满了就先点卡牌，再点上方要替换的那张。
- 点卡组里的卡选中它，再点一次就移出卡组。
- 「随机卡组」会生成一套搭配合理的卡组（包含胜利条件、大法术和防空手段）。
- 每局电脑都会随机组一套卡组。

## 内容

共 25 张卡（4 种稀有度：普通 / 稀有 / 史诗 / 传奇）：

| 类型 | 卡牌 |
|---|---|
| 近战 | 骑士(3) · 铁甲武士(4) · 旋斧战士(4，旋转范围攻击) · 哥布林(2) · 骷髅军团(3) · 枪骑兵(5，冲锋双倍伤害) |
| 远程 | 弓箭手(3) · 火枪手(4) · 法师(5，范围) · 炸弹兵(2，范围，只打地面) · 女巫(5，范围，每 7 秒召唤 3 个骷髅) |
| 空中 | 飞龙宝宝(4) · 蝙蝠群(2) · 热气球(5，只打建筑，坠毁爆炸) |
| 推进 | 巨人(5) · 野猪骑手(4，能跳过河) |
| 建筑 | 加农炮(3) · 墓碑(3，召唤骷髅) · 炼狱塔(5，伤害持续攀升) · 迫击炮(4，超远射程，有最小射程) |
| 法术 | 火球(4) · 万箭齐发(3) · 电击术(2，眩晕) · 冰冻术(4，冻结 4 秒) · 狂暴术(2，己方提速 35%，持续 6 秒) |

- 电脑对手分三档难度：简单 / 普通 / 困难。它会防守、反推、放建筑吸引火力、用法术补刀。
- 画面：俯视 18×32 格竞技场，河流和桥梁，3D 风格防御塔（国王塔睡眠后会激活，配有加农炮），出兵落地冲击波，火球爆炸，塔被摧毁时有碎石，屏幕震动，双倍圣水和加时横幅，皇冠结算界面。
- 音效由 WebAudio 实时合成。

角色和美术都是原创卡通造型，只借鉴了这类游戏的玩法和整体风格。
