# 皇家竞技场 · Royal Arena

一个类似《皇室战争》玩法的召唤对战小游戏：单个 `index.html` 文件，用纯 Canvas 绘制，没有依赖，也不需要构建。

## 怎么玩

- 用浏览器直接打开 `index.html`（手机竖屏体验最好；电脑上用鼠标也能玩）。
- 把下方卡牌**拖到己方半场**放置部队，或者先点卡牌再点场地。
- 圣水会自动回复，上限 10；最后 60 秒变成 **双倍圣水**。
- 摧毁一座公主塔得 1 顶皇冠；摧毁国王塔直接 3 冠获胜。
- 3 分钟结束时皇冠数相同，进入 1 分钟 **加时赛**（先拿到皇冠者胜）。
- 摧毁对方的公主塔之后，可以在那一路的敌方半场放置部队。
- 电脑键盘：数字键 1–4 选卡。

## 内容

| 卡牌 | 圣水 | 说明 |
|---|---|---|
| 骑士 | 3 | 近战，血量厚 |
| 弓箭手 | 3 | 2 名远程，可打空中单位 |
| 巨人 | 5 | 只攻击建筑的肉盾 |
| 骷髅军团 | 3 | 12 个骷髅，靠数量取胜 |
| 火球 | 4 | 范围法术，带击退 |
| 法师 | 5 | 远程范围伤害 |
| 哥布林 | 2 | 3 名快速近战 |
| 飞龙宝宝 | 4 | 飞行单位，范围喷火 |
| 铁甲武士 | 4 | （电脑卡组）高伤害近战 |
| 万箭齐发 | 3 | （电脑卡组）大范围箭雨 |

- 电脑对手分三档难度：简单 / 普通 / 困难。它会防守、反推、用火球补刀。
- 画面：俯视 18×32 格竞技场，河流和桥梁，3D 风格防御塔（国王塔睡眠后会激活，配有加农炮），出兵落地冲击波，火球爆炸，塔被摧毁时有碎石，屏幕震动，双倍圣水和加时横幅，皇冠结算界面。
- 音效由 WebAudio 实时合成。

角色和美术都是原创卡通造型，只借鉴了这类游戏的玩法和整体风格。
